# Jashira Illescas · Portafolio de arquitectura

Sitio estático (HTML, CSS y JavaScript; el 3D usa Three.js desde jsDelivr) publicado con GitHub Pages.

- `index.html`: portada con la maqueta 3D, los proyectos, otros proyectos y logros, el perfil y el contacto.
- `spare-parts-huancayo.html`: tienda construida con 2M MICON (2024–2025). Del prototipo al local, renders, planos de distribución y eléctricos, modelo 3D con avance de obra, cronograma, curva S y presupuesto con estructura S10.
- `vivienda-multifamiliar.html`: concepto, renders, plantas completas, elevación, corte y modelo 3D con tipologías y columnas.
- `centro-cultural-rimac.html`, `hospital-los-olivos.html`, `centro-cultural-canete.html`: proyectos de taller y de tesis, con mapas, estrategia paso a paso, planos y renders.
- `data/`: geometría de los modelos 3D, cronograma y presupuesto de la tienda y lista de proyectos de la maqueta.
- `descargas/`: CV, presupuesto (Excel) y cronograma (XML de MS Project) de la tienda.

Tipografías: Fraunces y Commissioner (Google Fonts). Transiciones entre páginas con View Transitions (Chrome, Edge y Safari recientes) y precarga con Speculation Rules (Chrome y Edge); en otros navegadores la página cambia sin transición. Los archivos CSS y JS llevan `?v=12` para que el navegador no muestre versiones viejas después de actualizar.
